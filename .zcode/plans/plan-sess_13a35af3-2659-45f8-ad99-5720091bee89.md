# MEGA Schedule App — Build Plan (rev. 2, UI-focused)

## What we're building
One shared React + TypeScript codebase shipped as **Windows .exe (Electron)**, **Android app (Capacitor)**, and browser dev preview. Local-first Dexie.js storage, **Supabase** sync between devices, AI layer (provider-agnostic adapter, MockProvider first) that parses exam schedules/timetables from photos/PDFs into reviewable tables, natural-language quick-add, and an assistant that reads your live data.

## UI Design System — built strictly from your 4 downloaded skills
Skills applied: `minimalist-ui` (primary aesthetic), `high-end-visual-design` (polish/motion), `ui-ux-pro-max` (app UX rules + persisted design tokens), `design-taste-frontend` (anti-slop discipline & state coverage).

**Direction: "Soft Editorial"** — calm, warm, premium. Explicitly anti-AI-slop.

- **Palette (soft):** warm bone canvas `#F7F6F3`, white/near-white cards `#FFFFFF/#FAFAF8`, hairline borders `#E9E7E2`, charcoal text `#2A2A28` (never pure black), secondary text `#7A7874`. One quiet primary accent: **muted sage** for active/selected/focus states. Course/category colors = desaturated pastels only (pale red/blue/green/yellow/lavender chips with deep-toned text). No gradients, no neon, no saturated fills.
- **Typography:** Plus Jakarta Sans (UI) + JetBrains Mono (times, dates, countdowns) + Newsreader serif *only* for the dashboard greeting/date line. Self-hosted fonts. Inter/Roboto banned.
- **Components:** cards with 14px radius, 1px hairline border + ultra-diffused warm shadow (< 0.05 opacity); buttons solid charcoal with soft radius; status tags as small uppercase pills in pastels. Icons: **Phosphor**, single weight, consistent stroke.
- **Motion:** Motion (`motion/react`) — staggered fade-rise entries, spring press feedback (`scale 0.98`), custom cubic-beziers, transform/opacity only, `prefers-reduced-motion` honored. Quiet, never flashy.
- **Dark mode:** included from day one (warm charcoal surfaces, same pastels adjusted, AA contrast verified in both themes).
- **App UX rules:** mobile bottom tab bar (≤5 tabs, 48dp targets, safe-area insets); desktop left sidebar + system tray. Every screen ships with loading skeletons, composed empty states, and inline error states.
- **Process:** first scaffold step runs `ui-ux-pro-max`'s design-system generator (persisted to `design-system/MASTER.md` as source of truth; needs Python — falls back to quick-reference tables if absent).

## Architecture
Single Vite app; thin Electron shell (`electron/`) and Capacitor config around it. Dexie (IndexedDB) local DB. Custom lightweight Supabase sync (`updated_at` + soft deletes, last-write-wins, single-user auth ties devices). AI adapter interface: `parseDocument(image|pdf)`, `parseQuickAdd(text)`, `chat(question, context)` — Gemini/OpenAI/Anthropic behind one interface, key stored locally. PDFs rendered to images via pdf.js → vision parse.

## Data model
`courses` · `class_slots` (recurring weekly rules + date range) · `exams` (+ auto "days to prepare") · `assignments` (course, due, priority, status) · `personal_items` · `ai_imports` (original + draft + corrections) · `settings`.

## Screens
Dashboard (next-up countdowns) · Timetable (weekly grid) · Exams · Assignments · Personal · Import (photo/PDF → side-by-side AI draft vs original → edit → confirm) · Assistant chat · Settings (notifications, AI provider/key, account, export JSON/CSV).

## Notifications
Desktop: tray-resident Electron + native toasts, re-hydrated at launch. Android: `@capacitor/local-notifications` with exact-alarm permission, reboot-persistent, battery-optimization setup guide in-app.

## Build phases
- **Phase 0 — Skeleton + design system:** scaffold, MASTER.md tokens, base components (buttons/cards/tags/inputs/nav), routing, Dexie schema, Supabase migrations + auth, sync engine. Deliverable: empty app running on laptop & phone with syncing shell. *You review the look here before we go further.*
- **Phase 1 — Foundation:** full CRUD everywhere, dashboard, timetable grid, notifications both platforms, settings, export. Deliverable: daily-usable app, zero AI.
- **Phase 2 — AI:** adapter + providers, document import with review flow, quick-add parsing, assistant.
- **Phase 3 — Candy (optional):** attendance, GPA tracker, Android widget, exam countdowns.
