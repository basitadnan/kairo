## Implementation steps

### A. Finish Phase 1 gaps
1. **Full CRUD**
   - `TasksScreen`: turn AddTaskModal into an add/edit modal (title/course/due/priority/status/notes); clicking a task row opens it prefilled; Delete button inside (soft-delete via existing `softDelete()` helper).
   - `PersonalScreen`: same pattern — row click reuses the item modal in edit mode + Delete.
   - **New `CoursesScreen` (`/courses`)**: full course management — list (color dot, name, code, credits/mark chips), tap to edit (name, code, color, credits, mark %), delete with cascade confirm (reuse logic from `CoursesModal`). Header shows a GPA summary card. Route in `App.tsx`; sidebar + More-screen entries.
2. **Data export/import** (`SettingsScreen`): "Export CSV" with dataset select (tasks / exams / timetable / personal items), proper RFC-4180 escaping; plus "Restore JSON backup" file input that upserts records preserving their sync stamps.
3. **Android notification hardening**
   - `AndroidManifest.xml`: add `POST_NOTIFICATIONS`, `SCHEDULE_EXACT_ALARM`, `RECEIVE_BOOT_COMPLETED`.
   - `notifications.ts`: forward-scheduler — generalize reminder computation over the next ~24h and register via `LocalNotifications.schedule({ schedule: { at } })` with deterministic ids hashed from reminder keys; refresh registrations on app start and on local data changes (existing bus); keep the 30s ticker as desktop/fallback path.
   - `SettingsScreen`: exact-alarm permission status row with fix button (`checkExactNotificationSetting`) + battery-optimization setup guide text (per plan).
4. **Reduced motion**: wrap app in `<MotionConfig reducedMotion="user">` (motion/react) + CSS `@media (prefers-reduced-motion: reduce)` guard in `globals.css`.
5. **Quick-add coverage**: add `QuickAddBar` to Tasks screen (and Schedule if it fits cleanly).

### B. Phase 3 — candy (all three)
6. **Attendance tracking**
   - `types.ts`: `AttendanceStatus = 'present' | 'late' | 'absent' | 'cancelled'`, `Attendance` record (courseId, slotId?, dateISO, status, note?) extending BaseRecord.
   - `db.ts` version 4: `attendance: 'id, courseId, slotId, dateISO, updatedAt, deleted'`; add to `SYNCED_TABLES`.
   - Marking UX: Dashboard's today-list rows get inline Present/Late/Absent/Cancelled buttons once a class has started; **new `AttendanceScreen` (`/attendance`)**: today section with marking, per-course stats bars (attended = present + late, cancelled excluded), recent history with change/delete. Sidebar + More entries.
   - Small bonus: feed an attendance one-liner into the assistant context.
7. **GPA tracker — percentage marks with configurable bands**
   - `Course` type += `credits?: number`, `markPct?: number`.
   - New `lib/gpa.ts`: default band table (A+ ≥90 → 4.0 … F <40 → 0), stored as JSON in settings key `gpa.bands`; `pctToPoints()`, `computeGpa()` = Σ(points × credits) / Σ credits over graded courses.
   - Credits + mark inputs live in the Courses screen edit modal; GPA card on that screen.
   - `SettingsScreen`: grading-bands editor (editable letter / min-% / points rows, reset-to-defaults).
8. **Android home-screen widget** (native, Java — avoids adding the Kotlin Gradle plugin)
   - `TodayWidgetProvider` (AppWidgetProvider + RemoteViews): app wordmark, today's next ≤4 classes (time · course · room), next-exam countdown line, graceful empty state before first snapshot.
   - `res/xml/today_widget_info.xml` (30-min system refresh) + `res/layout/widget_today.xml` row layouts matching Soft Editorial colors.
   - Tiny Capacitor plugin `WidgetBridgePlugin` (@CapacitorPlugin `saveSnapshot(json)` → SharedPreferences + immediate widget refresh), registered in `MainActivity`.
   - `src/lib/widget.ts`: builds snapshot from live DB (today's classes + next exam), debounced on bus changes + app start, native-only.
9. Refresh README roadmap statuses.
